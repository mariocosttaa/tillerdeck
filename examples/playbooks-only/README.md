# playbooks-only

A small Ansible project **without a Makefile** and without `ansible-mario.json`, used to test
detection: open it in Ansible Mario and the app proposes servers, the Shop product (API, web,
Postgres, Redis, nginx), migrations, backups and notifications from the playbooks and roles alone.

Nothing here connects anywhere: the inventories point at documentation addresses (`192.0.2.x`).
